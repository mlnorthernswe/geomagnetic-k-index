Inside KASM

A disturbed hour should have less influence on the estimate of regular daily variation. KASM first fits a smooth curve, measures the disturbance left in each hour, then fits again with less weight on active hours. Subtract that final curve to obtain the disturbance used for K.

Minute X / Y + adjacent-day context→Constant-weight fit→Hourly adaptive weights→Second fit→3-hour ranges → K

1. Estimate the regular daily variation twice

The first fit uses constant weights. The second uses weights derived separately from each component’s first-pass residual. Both fits balance closeness to the observations against the curve’s second differences.

2. Let the first residual set each hour’s influence

For each hour, measure max − min of the first-pass residual. A larger range lowers the weight of that hour’s observations in the second fit, allowing the quiet estimate to pass more smoothly through disturbances.

The smoothing objective and adaptive rule

For normalized measurements f and a candidate quiet curve s, each fit minimizes:

Σ (s[i] − 2s[i+1] + s[i+2])² + Σ w[i]² (f[i] − s[i])²
First fit: w² = 5 × 10⁻⁷ × smoothing
Second fit, each hour: q = min(hourly_range / 6.66 − 1, 50)
w = √(7 × 10⁻⁷ × smoothing) × exp(−q/2)
Relative data influence shown above = w² / (7 × 10⁻⁷ × smoothing) = exp(−q)

These are whole-window least-squares fits solved with Givens rotations. They are not a running average. A higher smoothing factor increases the data term’s weight for a fixed adaptive q; it is not a direct “make the curve smoother” control. The displayed variants rerun both actual solver stages.

3. Subtract the final curve and measure three-hour ranges

Residual = observation − final quiet estimate. Within each fixed UTC interval, the vertical marker spans its minimum to maximum. Each component’s range is classified separately.

4. Combine X and Y, then apply the original-range cap

Take the larger filtered component K, then cap it at the K obtained from the larger unfiltered component range. Select an interval to see the decision. Amber marks a cap that reduces K.

Try “Final K cap” at smoothing 1 and select 18–21 UTC: filtered X gives K=3, but the original range is below the K=3 boundary, so final K=2.

What happens at the edges and in gaps?

These examples use 180 minutes from each adjacent day, fitting 1,800 minutes together and reporting the central 1,440. The general calculator uses available context when an adjacent day is absent. Short internal gaps of up to six consecutive minutes are interpolated with the original minimum-curvature routine; longer gaps and missing boundary observations invalidate affected intervals. Both components must be valid, and the application also requires 90% observed coverage by default.
