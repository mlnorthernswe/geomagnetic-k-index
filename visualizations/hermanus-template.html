The filter builds an estimate of the regular daily variation, then subtracts it to reveal magnetic disturbances. Explore the actual calculation for Kiruna, 1 December 2023, using 1,440 minute means.

1. Separate the daily pattern from the observations

The daily mean is removed from the measurements. The green line is the final quiet curve after both L1 and L2 stages.

The pale green region marks the assumed daytime window. The filter adapts more slowly outside it.

2. Watch the first L1 pass build an estimate

The forward filter starts near zero because the data has been centered. It moves by small steps according to the sign of the error. The reverse filter traverses the day backward; averaging the two reduces the time shift.

This plot shows only the first rough L1 cascade. The algorithm then performs another L1 cascade and two L2 cascades to produce the final green curve above. L1 updates depend on error direction; L2 updates depend on error size. Very quiet data can skip L1 entirely.

3. Subtract the final quiet curve

Residual = centered measurement − final quiet curve. Within each fixed three-hour interval, its maximum minus minimum gives the component disturbance range.

4. Classify the ranges and keep the larger component K

Each X and Y range is classified with Kiruna’s K9-based thresholds. Combined K = max(KX, KY).

The example quiet-day settings originate from the supplied Hermanus reference and need calibration for Kiruna. The displayed K values are estimates, not an independent validation against hand-scaled indices. Changing μ updates actual precomputed filter results, not a cosmetic smoothing approximation.
